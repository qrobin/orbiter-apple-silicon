# Native flight display

This extends Orbiter's flight-view and green instrument language using a macOS window and menu bar. The simulation view is the primary surface. Preserve original spacecraft geometry, proportions and textures.

Use pale green symbology on the dark space backdrop; numeric instrument readouts use tabular figures. Keep orbit information at lower left and propulsion at lower right. Show current pause, time acceleration and attitude-assist state. Keep keyboard controls discoverable through the Flight menu and F1 overlay. Camera navigation is drag and scroll.

Native file dialogs handle scenario open/save and errors. Native focus behavior clears held inputs when the window loses focus. The minimum window is 900×600; the optional orbit diagram hides in narrower windows. Inherited physics and actual measurements supply every instrument value.

The glider systems panel uses native macOS controls in a scrollable utility window. Mechanisms show actual position and motion, engines use bounded continuous sliders, and pressure/thermal readouts reflect simulation state. M opens this panel. The original cockpit's supported click areas have equivalent large, accessible controls here.

In the virtual cockpit, suppress external instrument panels and use live native textures on the original MFD displays. Keep cockpit labeling in its original orientation. Switches and levers use original pivots and vertex ranges.
