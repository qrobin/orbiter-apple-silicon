# Delta-glider texture sources

The PNGs in this directory were produced with the built-in image generation tool from the corresponding original Orbiter DDS atlases. Both generated images shift parts of the UV layout, so they are **not** used directly. `../prepare_glider_ai_textures.py` transfers only limited fine luminance detail onto the original texture, protecting existing high-contrast markings and boundaries. The packaged DDS files are stored in `Native/GliderTextures`.

Prompts:

- Exterior: "Use case: precise-object-edit. Asset type: in-game UV texture atlas for the Orbiter Delta-glider spacecraft, viewed flat, not a render of a spacecraft. Input image is the exact atlas to edit. Restore and enhance its resolution and surface detail while preserving the original appearance, every UV island, silhouette, panel boundary, insignia, colors, text, hardware, and exact position at the same normalized pixel coordinates. The atlas must have exactly the same square composition, uncropped, with no perspective or camera view; absolutely no added or moved panels or markings. Only refine existing edges and worn metal details, keeping the original red, white, grey and green areas and a faithful match to the source. No new objects, no new writing, no watermark."
- Interior: "Use case: precise-object-edit. Asset type: Orbiter Delta-glider virtual cockpit UV texture atlas, flat square bitmap, not a picture of a cockpit. Input image is the exact atlas to edit. Enhance the resolution and refine the existing painted metal, glass and interior material details. Preserve the original design: every island boundary, shape, display, switch, light, label, panel, seam, shading, color and exact normalized position must remain fixed. Same square composition and framing, no cropping, perspective, rearrangement, invented objects, extra switches or text. The generated details must be subtle and suitable for an existing classic spacecraft game texture."
